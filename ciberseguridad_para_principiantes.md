# Ciberseguridad para principiantes

## Introducción

La ciberseguridad es el conjunto de prácticas, tecnologías y procesos utilizados para proteger sistemas informáticos, redes, dispositivos y datos frente a accesos no autorizados, ataques y otras amenazas.

La seguridad digital no depende únicamente de herramientas técnicas. Los hábitos de los usuarios también tienen un papel fundamental. Una contraseña débil, un enlace malicioso o una actualización pendiente pueden convertirse en puntos de entrada para un atacante.

## 1. ¿Qué es la ciberseguridad?

La ciberseguridad busca proteger tres elementos principales:

- **Confidencialidad:** solamente las personas autorizadas deben poder acceder a la información.
- **Integridad:** los datos deben mantenerse correctos y no ser modificados sin autorización.
- **Disponibilidad:** los sistemas y datos deben estar disponibles cuando sean necesarios.

Estos tres principios suelen conocerse como la **tríada CIA**: Confidentiality, Integrity and Availability.

### Ejemplo

Un banco necesita mantener confidenciales los datos de sus clientes, garantizar que las transacciones no sean modificadas incorrectamente y mantener sus servicios disponibles.

## 2. Contraseñas seguras

Las contraseñas son una de las primeras barreras de protección de una cuenta.

Una contraseña segura debe ser:

- Larga.
- Difícil de adivinar.
- Diferente para cada cuenta.
- Preferiblemente generada o almacenada mediante un gestor de contraseñas.

No es recomendable utilizar información fácil de relacionar con una persona, como nombres, fechas de nacimiento o mascotas.

### Gestores de contraseñas

Un gestor de contraseñas permite almacenar credenciales de forma segura y ayuda a utilizar contraseñas diferentes para cada servicio.

## 3. Autenticación multifactor

La autenticación multifactor, conocida como MFA, agrega una capa adicional de seguridad al inicio de sesión.

Puede requerir:

1. Algo que el usuario sabe: una contraseña o PIN.
2. Algo que el usuario tiene: un teléfono, una llave de seguridad o un dispositivo.
3. Algo que el usuario es: una característica biométrica.

La MFA reduce el impacto de una contraseña robada porque el atacante todavía necesita superar otro factor de autenticación.

## 4. Phishing

El phishing es una técnica de ingeniería social en la que un atacante intenta engañar a una persona para obtener información, instalar software malicioso o realizar una acción.

Un mensaje de phishing puede aparentar provenir de un banco, universidad, empresa, plataforma de compras o compañero de trabajo.

### Señales de alerta

- Mensajes que generan urgencia o miedo.
- Solicitudes inesperadas de contraseñas.
- Enlaces con dominios sospechosos.
- Errores extraños en el mensaje.
- Archivos adjuntos inesperados.
- Solicitudes de pagos o códigos de verificación.

Antes de hacer clic, conviene comprobar quién envió el mensaje y revisar cuidadosamente el destino del enlace.

## 5. Malware

Malware es un término general utilizado para describir software diseñado para realizar acciones perjudiciales o no autorizadas.

### Virus

Un virus puede incorporarse a archivos y propagarse cuando estos son ejecutados o compartidos.

### Gusanos

Los gusanos pueden propagarse entre sistemas aprovechando determinadas vulnerabilidades o conexiones de red.

### Troyanos

Un troyano aparenta ser un programa legítimo, pero realiza acciones no deseadas después de ser ejecutado.

### Ransomware

El ransomware puede impedir el acceso a archivos o sistemas y exigir un pago para recuperar el acceso.

### Spyware

El spyware está diseñado para recopilar información sobre las actividades de un usuario sin autorización.

## 6. Actualizaciones y parches

Las actualizaciones de software no solamente agregan funciones. También pueden corregir vulnerabilidades de seguridad.

Un sistema operativo, navegador o aplicación desactualizada puede contener fallos conocidos que los atacantes intenten aprovechar.

Por eso es recomendable:

- Mantener actualizado el sistema operativo.
- Actualizar navegadores y aplicaciones.
- Eliminar software que ya no se utiliza.
- Descargar actualizaciones desde fuentes oficiales.

## 7. Redes Wi-Fi

Para proteger una red doméstica se recomienda:

- Utilizar una contraseña fuerte.
- Cambiar la contraseña predeterminada del router.
- Mantener actualizado el firmware del router.
- Utilizar protocolos de seguridad modernos.
- Evitar realizar operaciones sensibles en redes públicas desconocidas.

Una red Wi-Fi pública no debe considerarse automáticamente segura solamente porque tenga una contraseña.

## 8. Ingeniería social

La ingeniería social consiste en manipular psicológicamente a una persona para conseguir información o provocar una acción.

Un atacante puede intentar aprovechar:

- Confianza.
- Miedo.
- Curiosidad.
- Urgencia.
- Autoridad.

### Ejemplo

Una persona recibe una llamada de alguien que afirma trabajar en soporte técnico y solicita un código de autenticación. Aunque la llamada parezca legítima, entregar ese código podría permitir que otra persona acceda a una cuenta.

La mejor defensa es verificar la identidad de quien realiza la solicitud mediante un canal independiente.

## 9. Copias de seguridad

Una copia de seguridad es una copia adicional de información que puede utilizarse para recuperarla después de una pérdida o incidente.

Las copias de seguridad pueden proteger frente a:

- Eliminación accidental.
- Fallos de hardware.
- Pérdida de dispositivos.
- Ransomware.
- Corrupción de archivos.

Una estrategia de respaldo debe considerar dónde se almacenan las copias, con qué frecuencia se realizan y cómo se recuperarán los datos.

## 10. Seguridad de dispositivos móviles

Los teléfonos inteligentes almacenan fotografías, mensajes, documentos, credenciales y otra información personal.

Algunas medidas recomendadas son:

- Utilizar bloqueo de pantalla.
- Mantener actualizado el sistema operativo.
- Instalar aplicaciones desde fuentes confiables.
- Revisar los permisos de las aplicaciones.
- Activar funciones de localización y borrado remoto cuando estén disponibles.
- Evitar instalar aplicaciones desconocidas.

## 11. Navegación segura

Antes de introducir información sensible se debe comprobar:

- El dominio del sitio.
- Que la conexión utilice HTTPS.
- Que el sitio sea realmente el servicio esperado.
- Que no existan redirecciones sospechosas.

HTTPS cifra la comunicación entre el navegador y el servidor, pero **no significa que el sitio sea automáticamente legítimo**. Un sitio malicioso también puede utilizar HTTPS.

## 12. Protección de datos personales

Algunos datos personales que pueden ser valiosos para atacantes son:

- Nombre completo.
- Número telefónico.
- Dirección.
- Correo electrónico.
- Fotografías.
- Información financiera.
- Credenciales.
- Información de ubicación.

Compartir menos información públicamente puede reducir las oportunidades de ingeniería social y otros ataques.

## 13. Seguridad en redes sociales

Las redes sociales pueden revelar información que un atacante utilice para intentar acceder a cuentas o manipular a una persona.

Es recomendable:

- Revisar la configuración de privacidad.
- Evitar publicar información sensible.
- No aceptar solicitudes de personas desconocidas sin verificar su identidad.
- Activar MFA.
- Revisar periódicamente las sesiones activas.

## 14. ¿Qué hacer ante un incidente de seguridad?

Si una persona sospecha que una cuenta fue comprometida, puede:

1. Cambiar la contraseña desde un dispositivo confiable.
2. Cerrar sesiones desconocidas.
3. Activar MFA.
4. Revisar movimientos o actividades recientes.
5. Contactar al proveedor del servicio si es necesario.
6. Informar a las personas afectadas si existe riesgo para ellas.
7. Conservar información relevante sobre el incidente.

## 15. Principios básicos para mantenerse seguro

- Utilizar contraseñas únicas y fuertes.
- Activar MFA.
- Mantener los dispositivos actualizados.
- Desconfiar de mensajes inesperados.
- Verificar enlaces antes de abrirlos.
- Realizar copias de seguridad.
- Proteger los dispositivos con bloqueo.
- Revisar los permisos de las aplicaciones.
- Compartir la menor cantidad posible de información sensible.
- Tener un plan para responder ante incidentes.

# Preguntas frecuentes

## ¿Una contraseña larga siempre es segura?

Una contraseña larga suele ser más resistente a ataques de adivinación, pero también importa que sea única y no sea fácilmente predecible.

## ¿MFA hace que una cuenta sea imposible de hackear?

No. MFA mejora considerablemente la protección, pero ningún mecanismo de seguridad garantiza protección absoluta.

## ¿HTTPS significa que una página es segura?

No necesariamente. HTTPS protege la comunicación, pero un sitio malicioso también puede utilizar HTTPS.

## ¿Por qué es importante actualizar el software?

Porque las actualizaciones pueden corregir vulnerabilidades conocidas y otros problemas de seguridad.

## ¿Qué diferencia hay entre phishing e ingeniería social?

El phishing es una técnica concreta que suele utilizar mensajes o sitios falsos para engañar a una persona. La ingeniería social es un concepto más amplio que incluye diferentes métodos de manipulación.

# Glosario

**Autenticación:** proceso mediante el cual un sistema verifica la identidad de un usuario.

**MFA:** autenticación que utiliza dos o más factores para verificar una identidad.

**Malware:** software diseñado para realizar acciones maliciosas o no autorizadas.

**Phishing:** técnica de engaño utilizada para obtener información o provocar acciones.

**Ransomware:** tipo de malware que puede bloquear o cifrar información y exigir un pago.

**Vulnerabilidad:** debilidad que puede ser aprovechada para comprometer un sistema.

**Firewall:** mecanismo que controla determinadas comunicaciones de red según reglas establecidas.

**Cifrado:** transformación de información para protegerla frente a accesos no autorizados.

**Backup:** copia de datos utilizada para facilitar su recuperación.

**Ingeniería social:** manipulación de personas para obtener información o provocar acciones.
